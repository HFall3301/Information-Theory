Lab 03 (Вариант 1): RSA для файлов

Что реализовано
- Ввод параметров RSA: p, q, d (закрытый ключ).
- Проверки ввода:
  - p и q простые, p != q.
  - r = p*q в диапазоне 256..65535.
  - d: 1 < d < phi(r), gcd(d, phi(r)) = 1.
- Вычисление параметров:
  - r = p*q
  - phi(r) = (p-1)*(q-1)
  - e как мультипликативная обратная величина к d по модулю phi(r).
- Шифрование файла:
  - каждый исходный байт (8 бит) шифруется отдельно;
  - результат каждого блока сохраняется как 16-битное значение (2 байта) в бинарный файл.
- Расшифрование файла:
  - вход читается как поток 16-битных блоков;
  - каждый блок превращается обратно в 8-битный байт.
- Вывод в интерфейсе:
  - получившиеся 16-битные блоки шифротекста показываются как числа в десятичной системе.

Алгоритмы
- Быстрое возведение в степень (mod_pow, бинарное возведение).
- Расширенный алгоритм Евклида для поиска обратного элемента.

Запуск
1. Перейти в каталог `lab-03`.
2. Выполнить:
   cargo run

Примечания
- Шифрование и расшифрование работают с файлами любого расширения.
- Формат шифротекста: бинарный, по 2 байта на каждый исходный байт.
